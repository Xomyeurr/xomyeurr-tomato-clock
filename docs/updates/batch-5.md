# 批次 5 更新：UI 調整與修正

批次 5（#20、#22–#26）已完成，版本更新為 `0.5.0`。

## 已完成

- 側邊欄新增「設定」入口，可直接打開 options page。
- 側邊欄把「時間軸」移到「專案排程」上方，並拆成獨立主題區塊。
- 今日 summary、時間軸與專案排程使用不同主題色和區塊圖示，提高辨識度。
- 今日建議時段改成可操作項目，每一段都有自己的「鎖定」按鈕，仍保留拖曳到其他建議時段以鎖定的操作。
- popup 隱藏 scrollbar，但保留原本的捲動能力。
- popup 開啟期間會持續刷新「今天剩餘」summary。
- Chrome popup 失焦自動關閉是瀏覽器平台限制，無法由 popup 內阻止；需要固定開著時改用側邊欄，popup 底部按鈕已改為「開側邊欄」。
